FIG. 04 — DELTA

표준 ↔ 실제, 무엇이 다른가

가장 큰 차이는 4번 노드, 도구 사용이다. 표준은 런타임에 LLM이 도구를 반복 호출하지만, 우리는 도구 호출을 LLM 호출 이전에 전부 끝낸다.

표준 — 런타임 자율 루프

LLM이 스스로 어떤 도구를 쓸지 판단
도구 호출 → 결과 관찰 → 다시 판단, 여러 차례 반복
메시지마다 도구 호출 횟수·순서가 달라질 수 있음

실제 — 결정론적 선실행

파이프라인이 컨텍스트를 전부 먼저 조립
LLM은 완성된 컨텍스트에 대해 딱 1회, 스키마 제약 분류만
같은 입력 → 같은 종류의 근거, 항상 재현 가능
왜 자유도를 뺐는가: 신뢰성(같은 입력엔 같은 근거) · 평가 가능성(무엇을 보고 판단했는지 항상 재현) · 비용/지연(메시지당 파이프라인 1회 + LLM 호출 1회) · 결정론을 요구하는 제출 규약 — 이 네 가지 때문에 의도적으로 런타임 자유 루프를 배제했다.
